# Code of Conduct

This repository is a space for reporting bugs and security issues related to Axon Server API. We expect the same 
baseline here as any professional space: be specific, stay on topic, and treat maintainers and other users with respect.

## Reporting

- **Bugs:** open an issue here with steps to reproduce, the Axon Server API version, and relevant logs.
  We read every issue, but response times follow your support tier, not GitHub's issue queue.
- **Security vulnerabilities:** do not open a public issue.
  Email [security-disclosure@axoniq.io](mailto:security-disclosure@axoniq.io) directly so we can assess and patch before
  disclosure.
- **Licensing questions:** go to your Axoniq account contact, not GitHub issues.

## Unacceptable behavior

Reports that are abusive, off-topic, or clearly bad-faith will be closed without response. This also includes using this
repository to solicit or distribute the source code or modified versions of it — per the license, this software is
source-available for inspection and internal-use modification only, and redistribution to third parties is not
permitted, here or elsewhere.

## Enforcement

Comments or reports that violate this Code of Conduct may be closed, edited, or locked at the maintainers' discretion.
Repeated or severe violations may result in the user being blocked from this repository.

If you believe someone is violating this Code of Conduct, or want to raise a conduct concern privately,
email [legal@axoniq.io](mailto:legal@axoniq.io).
